# pertemuan-01
1. kesinambungan PWD–DPW–DPWL;
Pwd merupakan pemrograman web dasar dimana mahasiswa belajar memahami dasar dasar html, ccs, js, PHP, mysql. DPW merupakan desain pemrograman web lanjutkan dari pwd di dpw ini mahasiswa belajar PHP dan membuat tampilan web lebih rapi dan terstruktur sesuai dengan fungsi. Dpwl merupakan desain pemrograman web lanjutan, di dpwl belajar cara membuat web dengan menggunakan mvc
2. perbedaan PHP terstruktur dan MVC;
PHP semua kode dan pemrosesan sampai tampilan HTML/CSS ditulis dalam satu berkas file yang sama
Sedangkan MVC kodenya di pisahkan menjadi 3 bagian yaitu model,view, controller
3. fungsi Model, View, dan Controller;
model: mengatur logika database dan data
view: mengatur tampilan HTML/CSS yang dilihat pengguna  
controller: menghubungkan model dan view
4. alur request–response MVC;
Browser, controller, model, basis data model controller, view, browser
5. pemetaan satu atau beberapa bagian/fitur aplikasi DPW ke Model, Controller, dan View disertai alasan; dan
Fitur pemesanan makanan di restoran 

Model: menangani logika bisnis data pesanan, mencatat id pesanan, daftar menu, total harga, dan status dapur yg masuk ke database server

Controller: mengatur alur pemrosesan pesanan yaitu dari request permintaan pembeli, memvalidasi ketersediaan menu, dan meneruskan data ke bagian dapur dan meja
View: arsip pesanan antarmuka pengguna(UI) menampilkan daftar menu makanan berdasarkan kategorinya.
6. kesimpulan P1.
Dapat disimpulkan bahwa DPWL merupakan tahap pematangan dalam pengembangan web melatih mahasiswa untuk membangun aplikasi secara profesional menggunakan arsitektur MVC (Model, View, Controller). Melalui DPWL, kodingan yang sebelumnya hanya terstruktur di tingkat DPWL dipisahkan secara sistematis antara logika database, pengatur alur aplikasi, dan tampilan antarmuka, sehingga menghasilkan struktur kode yang jauh lebih rapi, terorganisir, dan mudah dikembangkan dalam standar industri
